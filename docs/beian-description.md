# 绸缪 App 备案文案（个人开发者）

> 使用说明：提交腾讯云 App 备案时，"服务内容/用途描述"栏按表单字数限制二选一。
> 核心策略：突出工具属性，UGC 功能如实但轻描，明确非经营、无前置审批行业。

## 版本 A：完整版（约 160 字，适用于字数宽松的表单）

```
本应用为个人开发的实用生活工具类App，主要功能包括：个人记事与待办管理、
生日与日程提醒、日历查看、旅行攻略的整理与生成。为方便用户交流生活经验，
应用内提供攻略分享与评论功能，用户可发布美食、景点等生活类内容。本人已
建立完善的内容安全机制，包括发布内容自动审核、人工复审及用户举报处理，
确保展示内容合法合规。本应用为个人非经营性应用，不涉及新闻、出版、教育、
医疗、药品、金融等前置审批行业，不提供付费服务，严格遵守国家相关法律法规。
```

## 版本 B：精简版（约 70 字，适用于字数受限的表单）

```
个人开发的记事提醒工具应用，提供待办管理、生日提醒、日历及旅行攻略整理
功能，附带用户攻略分享与评论交流。已建立内容审核与举报机制，保障内容合规。
个人非经营性，无付费服务，不含前置审批行业内容。
```

## 电话核验口径（管局电核时照此回答）

**问：这个 App 是做什么的？**
> 个人用的记事和提醒工具，类似备忘录加日历，还能整理旅行攻略。

**问：有用户发布内容吗？**
> 有攻略分享和评论功能，但所有发布内容都经过机器加人工双重审核，还有用户举报机制，保障内容合法合规。

**问：是否涉及经营或收费？**
> 完全免费，没有任何付费功能，是个人兴趣开发。

**问：名称"绸缪"是什么意思？**
> 出自《诗经》"未雨绸缪"，寓意提前规划、有备无患，与提醒工具的定位一致。
