## 二、商店文案（可直接粘贴）

**一句话简介（≤20字）**
> 未雨绸缪，把每一件要紧事提前安排好

**应用介绍（通用版，各商店可裁剪）**
> 绸缪是一款专注"提前安排"的日程管理应用：
> · 日程与提醒：创建行程、倒计时、每日待办，精确到分钟的本地闹钟提醒，重启手机也不丢；
> · 国家名胜与旅行计划：内置全国名胜目的地灵感，一键生成出行计划清单；
> · 精灵 AI 助手：对话式生成行程安排（可选功能）；
> · 云同步：邮箱 / 手机号 / 微信登录，多设备数据同步；
> · 分享社区：把攻略与随拍分享给同好（可选功能）。
> 未雨而绸缪，有备而无患。

**关键词**
> 日程管理,提醒事项,倒计时,旅行计划,行程助手,待办清单,闹钟提醒

**图标**

**截图**：从手机截取 3–5 张（建议：首页日历、提醒详情、名胜/计划页、我的页）。商店一般要求 9:16 或 16:9，单张 ≤ 5MB。

## 三、上架前置（重要程度排序）

1. **App 备案（工信部，强制）**：2023 年起国内上架必须有 App 备案号。
   - 路径：腾讯云控制台 → 「App 备案」，主体选个人，填应用名"绸缪"+ 包名 `com.shiguang.reminder` + 平台 Android；
   - 备案需挂靠服务器/IP（你已有腾讯云 TCB 环境，可直接关联）；审核约 1–2 周；
   - 备案号要展示在应用内（设置页"关于"里加一行）并填进商店后台。
2. **软件著作权（部分商店要求）**：小米、应用宝等部分类目会要求《计算机软件著作权登记证书》或承诺函。可在中国版权保护中心办理（约 30–60 天）或先选不强制软著的渠道首发。
3. **开发者账号实名**：
   | 渠道 | 个人开发者 | 备注 |
   |---|---|---|
   | 华为应用市场 | ✅ 可 | 需实名 + App 备案 |
   | 小米应用商店 | ✅ 可 | 部分类目需软著 |
   | 应用宝 | ✅ 可 | 需 App 备案 |
   | OPPO / vivo | 视政策 | 倾向企业资质 |
   | Google Play | ✅ 可 | $25 一次性，无需国内备案，海外用户可先发这里 |
4. **正式签名 keystore**（见下）。

## 四、权限用途说明（商店后台要逐条填）

| 权限 | 用途 |
|---|---|
| INTERNET | 云同步、登录、内容加载 |
| POST_NOTIFICATIONS | 发送日程提醒通知 |
| SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM | 精确闹钟提醒 |
| RECEIVE_BOOT_COMPLETED | 重启后恢复提醒 |
| VIBRATE | 提醒震动 |
| FOREGROUND_SERVICE(+MEDIA_PLAYBACK) | 提醒铃声响铃服务 |
| USE_FULL_SCREEN_INTENT | 提醒全屏展示 |
| ACCESS_FINE/COARSE_LOCATION | 天气与名胜定位（可选授权） |
| RECORD_AUDIO / MODIFY_AUDIO_SETTINGS | 语音录入日程（可选授权） |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | 提示用户加白名单以保证提醒不丢 |

## 五、正式签名（上架前必须做）

```powershell
keytool -genkey -v -keystore shiguang-release.keystore -alias shiguang -keyalg RSA -keysize 2048 -validity 10950
```
- keystore 与密码务必离线保存（丢失后无法再更新应用）；
- 在 `android/app/build.gradle` 增加 signingConfig（release），或用环境变量注入；
- `gradlew assembleRelease` 生成上架用包。

## 六、登录方式与商店审核提示

- 应用含邮箱 / 手机号验证码 / 微信绑定码三种登录，测试账号请在商店后台"登录测试信息"中提供一个（可用 `测试邮箱 + 密码`）；
- 微信登录为"绑定码"模式（用户在小程序输入 6 位码），审核描述里写明"微信登录需在本应用小程序内确认"；
- 若使用短信登录做演示，注意网关限频（每号每分钟 1 条）。
