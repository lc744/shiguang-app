# 绸缪小程序 · 发布前自检清单

> 按顺序执行。前两项需要你在 mp.weixin.qq.com 后台操作，其余为核对项。

## ① 订阅消息模板（激活锁屏/后台推送，5 分钟）

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 左侧「功能 → 订阅消息 → 公共模板库」
2. 搜索关键词「**日程**」或「**提醒**」，选一个字段为 **事项/内容（thing 类型）+ 时间（time 类型）** 的模板（如"日程提醒"），点「选用」
3. 进入「我的模板」，复制 **模板 ID**（一串 `xxxx-xxxx-...`）
4. 把模板 ID 发给助手，或自己填两处：
   - `miniprogram/utils/config.js` → `SUBSCRIBE_TEMPLATE_ID`
   - `miniprogram/cloudfunctions/pushDue/secret.json` → `templateId`（从 `secret.template.json` 复制一份）
   - 同时把 secret.json 的 `fieldMap` 改成模板实际字段（模板里"事项"是 `thing1` 还是别的 key，后台模板详情页可见）
5. **创建定时触发器**：开发者工具 → cloudfunctions/pushDue 右键 → 「上传触发器」（代码已部署，只差这一步）
6. 验证：真机建一个 2 分钟后的事件，锁屏等待 → 应收到微信服务通知

> 费用：订阅消息免费；个人主体可用**一次性订阅**（用户每同意一次，可推送一条；拒绝则该次不推）。
> v1 范围：单次事件推送；每周重复/农历生日事件仍靠前台弹窗（数据未上云）。

## ② 用户隐私保护指引（不配真机会静默失败，10 分钟）

后台「设置 → 服务内容声明 → 用户隐私保护指引」→「新增指引」，声明以下类型（本项目实际用到的全部接口）：

| 信息类型 | 使用场景说明（可直接粘贴） |
|---|---|
| 麦克风 | 用于录制自定义提示音、语音输入对话 |
| 相册（仅写入） | 用于保存自定义表情图片 |
| 剪贴板 | 用于导出/导入数据备份 |
| 选中的照片或视频信息 | 用于从相册选择自定义表情 |
| 微信昵称 | 无（不要多勾，勾多了审核更严） |

- 处理说明统一填：「仅用于实现应用功能，不用于其他目的，不对外共享」
- 提交后等生效（一般即时），**发布新版本时指引会随之生效**

## ③ 提审材料核对

- [ ] 名称：绸缪（与代码、后台完全一致）
- [ ] 类目：工具 → 效率（个人主体可用）
- [ ] 简介：不带"最""第一"等绝对化用语，不提"备份到云端/同步"以外的敏感词
- [ ] 头像/截图：无 placeholder、无二维码、无其他平台水印
- [ ] 无诱导分享/关注逻辑（本项目无 ✓）
- [ ] 无虚拟支付（个人主体禁 ✓）
- [ ] 完善信息：后台「设置 → 基本设置」全部补齐

## ④ ICP 备案（最慢的一环，先启动）

- 2023-09 起新小程序**必须备案**才能提审
- 后台「设置 → 基本设置 → 小程序备案」按引导走（个人身份证 + 人脸核身），约 1~2 周
- 备案通过前可以先完善其余一切

## ⑤ 上传与提审

```
开发者工具 → 上传 → 填版本号 1.0.0 和备注 → 版本管理 → 提交审核
```

- 提审备注可写：「个人工具类小程序，无社交/支付功能；隐私指引已配置」
- 审核被拒最常见原因：类目不符、隐私指引缺失、简介含敏感词 —— 前四步做全基本不会遇到

## ⑥ 上线后开关

- `miniprogram/cloudfunctions/pushDue/secret.json` 的 `miniprogramState` 从 `"trial"` 改 `"formal"` 并重新部署 pushDue（否则正式版用户收不到推送）
- 云函数 pushDue 每分钟触发一次（月约 4.3 万次调用，个人免费额度内）
